How it works

Three primitives. You wire up the rest.

recallit does source ingestion, card generation, and honest grading. What sits around it, chat, voice, a GUI, a CLI, is entirely yours.

1

Feed it a source

A file, a URL, a repo, or just a concept. It builds cards that cite the exact line they came from, for any subject, a book, a language, a paper, a codebase. What it can't verify, it holds back.

2

It grades, not a model being nice

Code checks the answer against the cited line. For open-ended recall, code checks it against a rubric, a checklist of what a good answer covers, each point itself tied to a citable line. The rating is never up to the model, and never up to us: your cards are files on disk, not on a server.

3

You build the interface

recallit doesn't ship a UI opinion. Present, answer, grade, schedule: the primitives are the product. Build a chat agent, a voice loop, a dashboard, whatever your use case needs.
